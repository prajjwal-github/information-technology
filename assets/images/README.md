# Images

All photos come from the official IT department website (https://it.pccoepune.com/).
Logos come from the Computer department site, so the header works offline too.

| Folder / file          | Used on                                                        |
|------------------------|----------------------------------------------------------------|
| `banners/`             | Home hero slider (4 photos) and the About page banner and photo |
| `gallery/`             | Home page "Department Gallery" section                         |
| `events/`              | Event posters in the Home page "Workshops & Activities" card    |
| `students/`            | Photos in the Home page testimonials                           |
| `hod.jpg`              | HOD photo on Home and About pages                              |
| `logo/`                | PCCOE and PCET logos in the header, and the favicon            |

To swap a photo, replace the file with one of the same name, or change the path in
`index.html` / `about.html`. If a photo is missing the page still looks complete
(the slider falls back to the blue gradient, the HOD card and testimonials show initials).
